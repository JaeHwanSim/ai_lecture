# 📖 **5장. 머신러닝 개요**


## ✨ 1. 머신러닝이란 무엇인가

머신러닝(Machine Learning)이란,  
명시적으로 프로그램을 작성하지 않고도 데이터를 이용하여 컴퓨터가 스스로 학습하고 성능을 개선하는 기술입니다.

Arthur Samuel은 머신러닝을 "**명시적으로 프로그래밍하지 않고 컴퓨터가 학습할 수 있게 하는 연구 분야**"라고 정의하였습니다.

머신러닝은 입력 데이터로부터 패턴을 학습하여,  
**새로운 데이터에 대해 예측하거나 분류하는 모델**을 구축하는 것을 목표로 합니다.

### ➡️ 머신러닝 기본 구성 요소
| 구성 요소 | 설명 |
|:--|:--|
| 데이터 | 학습 및 예측을 위한 입력 자료 |
| 모델 | 데이터의 패턴을 학습하는 구조 |
| 학습 알고리즘 | 모델을 최적화하는 방법 |
| 예측 | 학습한 모델로 새로운 데이터에 대한 결과 생성 |

## ✨ 2. 머신러닝의 주요 분류

머신러닝은 학습 방식에 따라 크게 세 가지로 분류됩니다.

| 분류 | 설명 | 예시 |
|:--|:--|:--|
| 지도학습 (Supervised Learning) | 입력과 정답(label)을 이용하여 학습 | 분류(Classification), 회귀(Regression) |
| 비지도학습 (Unsupervised Learning) | 정답 없이 데이터 구조를 학습 | 클러스터링(Clustering), 차원 축소(Dimensionality Reduction) |
| 강화학습 (Reinforcement Learning) | 보상을 통해 최적 행동을 학습 | 게임 플레이, 로봇 제어 |

---

## ✨ 3. 머신러닝 워크플로우

머신러닝 프로젝트는 다음과 같은 단계를 거칩니다.

### ➡️ 전형적인 머신러닝 워크플로우

1. **문제 정의**
2. **데이터 수집**
3. **데이터 전처리 및 탐색**
   - 결측치 처리와 이상값 탐지
   - 범주형 변수 인코딩
   - 정규화와 표준화
4. **특성 선택 및 생성**
5. **모델 선택 및 학습**
   -  데이터 분할: 학습/검증/테스트셋
6. **모델 평가**
7. **모델 개선 및 최적화**
8. **최종 모델 배포**

```
데이터 수집 → 데이터 전처리 → 모델 학습 → 모델 평가 → 하이퍼파라미터 튜닝 → 최종 예측
```

- 이 과정에서 **데이터 전처리와 모델 선택**이 성능에 가장 큰 영향을 미칩니다.
---

### ➡️ 결측치(Missing Value) 처리

머신러닝 모델은 결측값을 포함하는 데이터를 직접 다루지 못하는 경우가 많습니다.  
따라서 적절한 방법으로 결측값을 처리해야 합니다.

| 방법 | 설명 | 예시 |
|:--|:--|:--|
| 삭제 (Drop) | 결측치가 있는 행 또는 열을 제거 | `dropna()` |
| 대체 (Imputation) | 평균, 중앙값, 최빈값 등으로 대체 | `fillna(value)` |

&gt; ✅ 데이터의 분포를 고려하여 대체하는 것이 중요합니다.

### ➡️ 이상값(Outlier) 탐지

이상값은 데이터 분포에서 벗어난 값입니다.  
주로 IQR, Z-Score 등을 활용하여 탐지합니다.

| 방법 | 설명 |
|:--|:--|
| IQR 방법 | Q1, Q3 기준으로 이상 범위 외 값 탐지 |
| Z-Score 방법 | 평균 대비 표준편차 범위를 벗어난 값 탐지 |


### ➡️ 범주형 변수 인코딩

머신러닝 모델은 수치형 데이터만 입력으로 받기 때문에,  
범주형(categorical) 데이터는 수치로 변환해야 합니다.

| 인코딩 방법 | 설명 | 예시 |
|:--|:--|:--|
| 레이블 인코딩 (Label Encoding) | 각 카테고리를 정수로 매핑 | Male → 0, Female → 1 |
| 원-핫 인코딩 (One-Hot Encoding) | 각 카테고리를 0/1로 변환하는 벡터 생성 | `get_dummies(), to_categorical()` 사용 |


### ➡️ 정규화와 표준화

특성(feature)들의 스케일이 다를 경우,  
머신러닝 모델은 특정 특성에 지나치게 민감하게 반응할 수 있습니다.  
이를 방지하기 위해 스케일 조정이 필요합니다.

| 방법 | 설명 | 수식 |
|:--|:--|:--|
| 정규화 (Normalization) | 모든 값을 0~1 범위로 변환 | $x' = \frac{x - x_{min}}{x_{max} - x_{min}}$ |
| 표준화 (Standardization) | 평균 0, 표준편차 1로 변환 | $x' = \frac{x - \mu}{\sigma}$ |

&gt; ✅ KNN, SVM 같은 거리 기반 알고리즘은 정규화/표준화가 매우 중요합니다.


### ➡️ 4. 데이터 분할: 학습/검증/테스트셋

모델의 성능을 정확히 평가하기 위해, 데이터를 다음과 같이 분할합니다.

| 구분 | 설명 | 일반적인 비율 |
|:--|:--|:--|
| 학습셋 (Training Set) | 모델을 학습시키는 데이터 | 60~80% |
| 검증셋 (Validation Set) | 하이퍼파라미터 튜닝용 데이터 | 10~20% |
| 테스트셋 (Test Set) | 최종 성능 평가용 데이터 | 10~20% |

&gt; ✅ 교차 검증(Cross Validation) 기법을 사용하면 보다 안정적인 평가가 가능합니다.

# 📖  6장. 회귀 분석(Regression)

회귀 분석은 **연속적인 값을 예측**할 때 사용하는 대표적인 기계학습 알고리즘입니다.

| 항목      | 설명                                                |
| ------- | ------------------------------------------------- |
| 목적      | 입력 변수로부터 수치형 출력값 예측                               |
| 대표 알고리즘 | 선형 회귀(Linear Regression), 릿지 회귀(Ridge), 라쏘(Lasso) |

### 적용 예

* 기상 데이터 기반 **수확량 예측**
* 강 근처, 방의 갯 수 등의 주거 상황 기반 **집값 예측**
---

# 📘 [1] 선형 회귀 (Linear Regression)

## 1. 역사적 배경

#### 1.. 기원

* **1805년**: 프랑스 수학자 **아드리앵마리 르장드르(Adrien-Marie Legendre)**가 ‘최소제곱법(Least Squares Method)[https://blog.naver.com/knmds/10087938003]’을 도입하여 천문학적 관측 데이터의 오차를 최소화하려 했습니다.
* **1809년**: 독일 수학자 **Carl Friedrich Gauss**도 동일한 방법을 독자적으로 개발하여 **정규분포와의 연결**을 이론화하였습니다.

#### 2.. 통계학으로의 확장

* **19세기 후반**: 통계학자 **Francis Galton**이 인간 키의 상관관계 분석을 통해 ‘회귀(regression)’라는 용어를 도입하였습니다.

  * 아버지 키와 아들 키 간의 관계에서 평균으로 되돌아가는 성질 → “회귀(regression) toward the mean”

#### 3.. 컴퓨터 시대 이후

* 20세기 중반 이후 회귀 분석은 컴퓨터를 통해 자동화되며 통계학, 경제학, 공학, 생물학 등 다양한 분야에서 **기초 예측 도구**로 자리잡게 됩니다.

---

## 2. 이론적 알고리즘 

#### 1.. 목표
입력 변수 $X$와 출력 변수 $y$ 사이의 **선형 관계**를 모델링하여, 새로운 입력 값에 대한 **연속적 출력 값**을 예측하는 것.

#### 2.. 수식 표현

$$
\hat{y} = w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b = \mathbf{Xw} + b
$$

* $\hat{y}$: 예측값
* $\mathbf{X}$: 입력 벡터
* $\mathbf{w}$: 가중치 벡터
* $b$: 절편(intercept)

#### 3.. 목적 함수 (비용 함수 Cost Function, 손실 함수 Loss Function)

**MSE (Mean Squared Error)**를 사용하여 오차를 최소화합니다:

$$
J(\mathbf{w}, b) = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
$$

---

## 3. 가정 조건

선형 회귀는 다음의 통계적 가정을 전제로 합니다:

| 가정                              | 설명                    |
| ------------------------------- | --------------------- |
| 선형성 (Linearity)                 | 입력 변수와 출력 변수 간의 선형 관계 |
| 독립성 (Independence)              | 관측값 간의 독립성            |
| 등분산성 (Homoscedasticity)         | 오차의 분산이 일정함           |
| 정규성 (Normality)                 | 잔차(오차)가 정규 분포를 따름     |
| 다중공선성 없음 (No multicollinearity) | 입력 변수 간 과도한 상관관계 없음   |

---
## 4. 회귀 분석 flow

1. 데이터 수집: 센서 or 측정 데이터
2. 특성 선택: 평균 지름, 대칭성, 누적 지름 증가량 등
3. 모델 학습: 선형 회귀(linear regression) 또는 다항 회귀(polynomial regression)
4. 성능 평가: MAE(Mean Absolute Error), RMSE(Root Mean Squared Error), R²
---
## 5. 경사하강법


선형회귀는 예측값과 실제값의 차이를 최소화해야 함.
이를 위해 사용하는 손실 함수는 **평균제곱오차(MSE)**:

$$
J(\beta) = \frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2 = \frac{1}{n} \sum_{i=1}^n (y_i - (\beta_0 + \beta_1 x_i))^2
$$

&gt; 이 함수를 **최소화하는 $\beta$ 값을 찾는 것**이 핵심!

---
### 선형회귀를 푸는 방법론: 정규방정식 vs 경사하강법

| 방법        | 특징                        |
| --------- | ------------------------- |
| **정규방정식** | 직접 해를 구함, 빠름, 소규모 데이터에 적합 |
| **경사하강법** | 반복 계산, 대규모/온라인 학습/딥러닝에 적합 |



* 이 손실 함수는 **볼록(convex) 함수**이므로 최솟값이 존재함.
* 이 최솟값을 찾기 위한 방법 중 하나가 **경사하강법(Gradient Descent)**임.

---
### 경사하강법으로 선형회귀를 푸는 과정

1. $\beta_0, \beta_1$의 초기값을 정함

2. 손실 함수의 **기울기(미분값)** 계산:

   $$
   \frac{\partial J}{\partial \beta_0}, \quad \frac{\partial J}{\partial \beta_1}
   $$

3. 아래와 같이 반복적으로 업데이트:

   $$
   \beta_j := \beta_j - \alpha \cdot \frac{\partial J}{\partial \beta_j}
   $$

   ($j = 0, 1$, $\alpha$는 학습률)

4. 손실 함수 값이 거의 변하지 않거나 일정 횟수만큼 반복하면 종료

---
### 경사하강법으로 계수를 업데이트 하는 과정

#### 회귀식

$$
\hat{y}_i = \beta_0 + \beta_1 x_i
$$

 - $x_i$: 입력값
 - $y_i$: 실제값
 - $\hat{y}_i$: 예측값

#### 손실 함수 (MSE: 평균제곱오차)

$$
J(\beta_0, \beta_1) = \frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2
= \frac{1}{n} \sum_{i=1}^n (y_i - (\beta_0 + \beta_1 x_i))^2
$$


#### 손실 함수의 편미분 (기울기)

* (1) $\frac{\partial J}{\partial \beta_0}$

$$
\frac{\partial J}{\partial \beta_0} 
= \frac{2}{n} \sum_{i=1}^n (\hat{y}_i - y_i)
$$


* (2) $\frac{\partial J}{\partial \beta_1}$

$$
\frac{\partial J}{\partial \beta_1} 
= \frac{2}{n} \sum_{i=1}^n (\hat{y}_i - y_i) \cdot x_i
$$

---
#### 경사하강법 업데이트 식

학습률(learning rate) $\alpha$를 이용해서 파라미터를 다음과 같이 업데이트함:

$$
\beta_0 := \beta_0 - \alpha \cdot \frac{\partial J}{\partial \beta_0}
$$

$$
\beta_1 := \beta_1 - \alpha \cdot \frac{\partial J}{\partial \beta_1}
$$

---

### 예제:

| $x$ | $y$ |
| --- | --- |
| 1   | 2   |
| 2   | 4   |

초기값:

* $\beta_0 = 0$, $\beta_1 = 0$
* 학습률 $\alpha = 0.1$



####  1번째 반복:

 - 예측값:

  $$
  \hat{y}_1 = 0 + 0 \cdot 1 = 0,\quad \hat{y}_2 = 0 + 0 \cdot 2 = 0
  $$
 - 오차:

  $$
  \hat{y}_1 - y_1 = -2,\quad \hat{y}_2 - y_2 = -4
  $$

 - 기울기 계산:

$$
\frac{\partial J}{\partial \beta_0} = \frac{2}{2}(-2 + -4) = -6
$$

$$
\frac{\partial J}{\partial \beta_1} = \frac{2}{2}(-2 \cdot 1 + -4 \cdot 2) = -10
$$

 - 파라미터 업데이트:

$$
\beta_0 := 0 - 0.1 \cdot (-6) = 0.6
$$

$$
\beta_1 := 0 - 0.1 \cdot (-10) = 1.0
$$



####  업데이트 후 모델:

$$
\hat{y} = 0.6 + 1.0x
$$


---
### 경사하강에 의한 선형회귀 코드

```python
import numpy as np
import matplotlib.pyplot as plt

# 1. 데이터 생성 (y = 2x + 3 + noise)
np.random.seed(0)
X = 2 * np.random.rand(100, 1)
y = 2 * X + 3 + np.random.randn(100, 1) * 0.5  # noise 추가

# 2. 경사하강법으로 선형회귀 구현
# 초기 파라미터 설정
theta_0 = 0.0  # 절편 (bias)
theta_1 = 0.0  # 기울기 (weight)

# 학습률과 반복 수
alpha = 0.1
epochs = 100

# 저장용 리스트
theta_0_list = []
theta_1_list = []
loss_list = []

# 경사하강법 반복
n = len(X)
for i in range(epochs):
    y_pred = theta_1 * X + theta_0
    error = y_pred - y
    loss = (1/n) * np.sum(error**2)

    grad_0 = (2/n) * np.sum(error)
    grad_1 = (2/n) * np.sum(error * X)

    theta_0 -= alpha * grad_0
    theta_1 -= alpha * grad_1

    theta_0_list.append(theta_0)
    theta_1_list.append(theta_1)
    loss_list.append(loss)

# 최종 파라미터로 예측
y_final_pred = theta_1 * X + theta_0

# 시각화
plt.figure(figsize=(10, 4))

# 산점도 + 회귀선
plt.subplot(1, 2, 1)
plt.scatter(X, y, label='Data')
plt.plot(X, y_final_pred, color='red', label='Fitted Line')
plt.title('Linear Regression by Gradient Descent')
plt.xlabel('X')
plt.ylabel('y')
plt.legend()

# 손실값 그래프
plt.subplot(1, 2, 2)
plt.plot(loss_list)
plt.title('Loss over Epochs')
plt.xlabel('Epoch')
plt.ylabel('MSE Loss')

plt.tight_layout()
plt.show()

```

## 7. 데이터 표준화 vs. 비표준화


### 표준화가 **필요한 경우**

| 조건                                                    | 설명                                                                    |
| ----------------------------------------------------- | --------------------------------------------------------------------- |
| 여러 변수의 \*\*스케일(단위)\*\*가 매우 다를 때                       | 예: 어떤 변수는 키(cm), 어떤 변수는 연봉(천만 원) 등, 단위가 다르면 회귀계수가 비교 불가하거나 특정 변수에 편향됨 |
| **정규화된 계수(베타값) 해석**이 필요할 때                            | 표준화된 회귀계수는 각 변수의 영향력을 직접 비교할 수 있어 해석이 쉬움                              |
| \*\*정규화 기반 정규화 기법 (Lasso, Ridge)\*\*를 쓸 때             | Lasso나 Ridge는 회귀계수에 패널티를 주는데, 스케일이 다르면 패널티가 공정하지 않게 적용됨               |
| \*\*다변량 분석(Multiple Regression)\*\*에서 변수 간 중요도를 비교할 때 | 표준화하면 변수들의 상대적 중요도를 해석할 수 있음                                          |

---

### 표준화가 **불필요한 경우**

| 조건                         | 설명                                                                 |
| -------------------------- | ------------------------------------------------------------------ |
| 단순 선형 회귀 (변수가 하나일 때)       | 변수 간 비교가 필요 없으므로 스케일 차이가 문제되지 않음                                   |
| 모든 독립변수가 **같은 단위**를 가질 때   | 예: 모두 cm 단위라면 스케일 차이로 인한 영향 없음                                     |
| 회귀계수의 **절대값 자체에 의미**가 있을 때 | 예: 변수 1이 증가할 때 반응변수가 얼마나 증가하는지를 실제 단위로 해석하고 싶을 때                   |
| 목적이 예측이지 해석이 아닐 때          | 예측 정확도가 중요하고 계수 해석이 중요하지 않은 경우에는 반드시 표준화할 필요 없음 (단, 정규화 기반 회귀는 예외) |

# 📘 [3] 로지스틱 회귀(Logistic Regression)


## 1. 로지스틱 회귀란?


로지스틱 회귀는 **분류(classification)** 문제를 해결하는 지도 학습 알고리즘입니다. 이름은 "회귀"이지만, 실제로는 **출력값을 확률로 예측하고, 이 확률을 바탕으로 클래스(0 또는 1)를 분류**하는 데 사용됩니다. 선형 회귀의 결과를 **시그모이드 함수**를 통해 0과 1 사이의 확률로 해석함.



로지스틱 회귀 결정 경계는 다음 수식을 기반으로 함:

$$
z = w_1 x_1 + w_2 x_2 + b \quad\text{→ 분류 기준: } z = 0
$$

$$
p = \frac{1}{1 + e^{-z}} \quad\text{→ 시그모이드 확률}
$$

* 확률이 0.5인 지점: z = 0 → 결정 경계

* 출력값(p) &gt;= 0.5 이면, **1**로 분류, 1일 확률은 p 

$$
P(y = 1 | \mathbf{x}) = \hat{y} = \sigma(z)
$$

* 출력값(p) &lt; 0.5 이면, **0**으로 분류, 0일 확률은 (1-p)
$$
P(y = 0 | \mathbf{x}) = 1 - \hat{y} = 1 - \sigma(z) 
$$

(시그모이드 함수)[https://en.wikipedia.org/wiki/Logistic_function]:


* **이진 분류**에 주로 사용되며, **다중 클래스 확장**(scikit learn에서 지원)도 가능합니다.


| 항목    | 설명                                      |
| ----- | --------------------------------------- |
| 목적    | 확률 기반 이진 분류                             |
| 예측값   | 시그모이드 함수 출력 $\hat{y} \in (0,1)$         |
| 결정 기준 | $\hat{y} \ge 0.5 \rightarrow 1$, 그 외는 0 |
| 손실 함수 | 로지스틱 손실 (Binary Cross-Entropy)          |
| 최적화   | 경사하강법 등 사용                              |
| 확장    | Scikit-learn은 다중 클래스 분류 가능                |

---

## 2. 로지스틱 회귀의 손실함수: Cross Entropy

### 🔹 수식 표현:

이진 분류에서 로지스틱 회귀는 **Cross Entropy (교차 엔트로피)** 손실 함수를 사용함.

$$
\mathcal{L}(y, \hat{y}) = -\left[y \log(\hat{y}) + (1 - y)\log(1 - \hat{y})\right]
$$

여기서:

* $y \in \{0, 1\}$: 실제 라벨
* $\hat{y} \in (0, 1)$: 예측 확률

### 🔹 벡터 형태 (전체 데이터 손실):

$$
J(\mathbf{w}) = \frac{1}{N} \sum_{i=1}^{N} \left[-y_i \log(\hat{y}_i) - (1 - y_i)\log(1 - \hat{y}_i)\right]
$$


### 🔹 Cross Entropy 수식 유도 과정

#### 1) 출력값:

로지스틱 회귀는 확률 $P(y=1|\mathbf{x}) = \hat{y}$ 를 예측.

#### 2) 우도(Likelihood) 함수:

$$
L(\mathbf{w}) = \prod_{i=1}^{N} \hat{y}_i^{y_i} (1 - \hat{y}_i)^{1 - y_i}
$$

#### 3) 로그 우도(Log-Likelihood):

$$
\log L(\mathbf{w}) = \sum_{i=1}^{N} \left[ y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i) \right]
$$

#### 4) 비용함수로 전환 (음의 로그우도):

$$
J(\mathbf{w}) = -\log L(\mathbf{w}) = -\sum_{i=1}^{N} \left[ y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i) \right]
$$

이렇게 **Cross Entropy**는 확률 기반 모델에서 **최대우도 추정(Maximum Likelihood Estimation)**의 음의 로그 우도와 같음.

#### 복습 문제 1: Cross Entropy 손실 함수가 최소가 되는 경우는 언제인가?

A. 예측 확률이 항상 0.5일 때

B. 예측 확률이 실제 라벨과 최대한 멀 때

C. 정보 이론

**설명:** Cross Entropy는 Claude Shannon의 정보 이론에서 유래된 개념임.

### 파이썬 구현 예제

```python
import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def cross_entropy_loss(y_true, y_pred, eps=1e-15):
    y_pred = np.clip(y_pred, eps, 1 - eps)  # log(0) 방지
    return -np.mean(y_true * np.log(y_pred) + (1 - y_true) * np.log(1 - y_pred))

# 예제 데이터
X = np.array([[0.2, 0.4], [0.5, 0.9], [1.0, 1.0]])
w = np.array([1.0, -1.0])
b = 0.0

z = X @ w + b # np.matmul(X, w)
y_pred = sigmoid(z)

# 실제 정답 라벨
y_true = np.array([0, 1, 1])

# 손실 계산
loss = cross_entropy_loss(y_true, y_pred)
print("Cross Entropy Loss:", loss)
```


#### 사용 함수 설명표

| 함수명                                  | 기능            | 주요 파라미터                          | 설명              |
| ------------------------------------ | ------------- | -------------------------------- | --------------- |
| `sigmoid(z)`                         | 시그모이드 함수      | `z`: 선형 입력값                      | 0\~1 사이의 확률로 변환 |
| `cross_entropy_loss(y_true, y_pred)` | 교차 엔트로피 손실 계산 | `y_true`: 실제 정답, `y_pred`: 예측 확률 | 분류 모델에서 손실 계산   |
| `np.clip`                            | 값 범위 제한       | `eps`: 아주 작은 값                   | log(0) 발생 방지 목적 |
---

## 3. 경사하강에 의한 로지스틱 회귀


손실 함수 $J(\theta)$를 파라미터 $\theta_j$에 대해 편미분해서
**기울기 공식**은 다음과 같이 도출됨:

$$
\frac{\partial J(\theta)}{\partial \theta_j} = \frac{1}{n} \sum_{i=1}^n (\hat{y}_i - y_i) \cdot x_{ij}
$$


| 기호                                                 | 의미              |
| -------------------------------------------------- | --------------- |
| $x_{ij}$                                           | i번째 샘플의 j번째 입력값 |
| $\theta_j$                                         | 우리가 찾고 싶은 파라미터  |
| $z_i = \sum_j \theta_j x_{ij}$                     | 선형 조합 (가중치 합)   |
| $\hat{y}_i = \sigma(z_i) = \frac{1}{1 + e^{-z_i}}$ | 시그모이드 함수로 예측 확률 |
| $y_i$                                              | 실제 정답값 (0 또는 1) |



#### 전체 손실 함수:

$$
J(\theta) = -\frac{1}{n} \sum_{i=1}^n \left[ y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i) \right]
$$

#### **$\theta_j$**에 대한 편미분을 수행

손실 함수는 직접 $\theta_j$에 의존하지 않고,
→ $\theta_j \rightarrow z_i \rightarrow \hat{y}_i \rightarrow J$
이렇게 **연결(chain)**되어 있으므로,

→ 따라서 **체인 룰(Chain Rule)**을 사용!


$$
\frac{\partial J}{\partial \theta_j}
= \sum_{i=1}^n \frac{\partial J}{\partial \hat{y}_i}
\cdot \frac{\partial \hat{y}_i}{\partial z_i}
\cdot \frac{\partial z_i}{\partial \theta_j}
$$


#### ① $\frac{\partial J}{\partial \hat{y}_i}$

이건 log 손실 함수에서 나옴:

$$
\frac{\partial}{\partial \hat{y}_i} \left[ -y_i \log(\hat{y}_i) - (1 - y_i) \log(1 - \hat{y}_i) \right]
= -\frac{y_i}{\hat{y}_i} + \frac{1 - y_i}{1 - \hat{y}_i}
$$


#### ② $\frac{\partial \hat{y}_i}{\partial z_i}$

$$
\hat{y}_i = \sigma(z_i) = \frac{1}{1 + e^{-z_i}}
\Rightarrow \frac{d\hat{y}_i}{dz_i} = \hat{y}_i (1 - \hat{y}_i)
$$


#### ③ $\frac{\partial z_i}{\partial \theta_j}$

$$
z_i = \sum_j \theta_j x_{ij}
\Rightarrow \frac{\partial z_i}{\partial \theta_j} = x_{ij}
$$


- 모두 곱하면

$$
\frac{\partial J}{\partial \theta_j}
= \sum_{i=1}^n 
\left(
\left(-\frac{y_i}{\hat{y}_i} + \frac{1 - y_i}{1 - \hat{y}_i} \right)
\cdot \hat{y}_i (1 - \hat{y}_i)
\cdot x_{ij}
\right)
$$

➡ 결과적으로:

$$
\frac{\partial J}{\partial \theta_j}
= \sum_{i=1}^n (\hat{y}_i - y_i) \cdot x_{ij}
$$

- 평균을 내면:

$$
\boxed{
\frac{\partial J}{\partial \theta_j}
= \frac{1}{n} \sum_{i=1}^n (\hat{y}_i - y_i) \cdot x_{ij}
}
$$

## 4. 경사 하강에 의한 로지스틱 회귀 

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split

# 1. 데이터 생성 (2D 이진 분류 문제)
X, y = make_classification(n_samples=200, n_features=1, n_informative=1, 
                           n_redundant=0, n_clusters_per_class=1, flip_y=0.05, random_state=0)

# 2. 시그모이드 함수
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

# 3. 로지스틱 손실 함수
def compute_loss(y_true, y_pred):
    epsilon = 1e-15  # 로그 안정성
    y_pred = np.clip(y_pred, epsilon, 1 - epsilon)
    return -np.mean(y_true * np.log(y_pred) + (1 - y_true) * np.log(1 - y_pred))

# 4. 경사하강법 구현
def logistic_regression_gd(X, y, lr=0.1, epochs=100):
    n = X.shape[0]
    X_b = np.c_[np.ones((n, 1)), X]  # 절편항 포함
    theta = np.zeros(X_b.shape[1])  # 초기 파라미터 [theta_0, theta_1]

    loss_history = []

    for epoch in range(epochs):
        z = X_b @ theta
        y_pred = sigmoid(z)
        error = y_pred - y
        grad = X_b.T @ error / n
        theta -= lr * grad
        loss = compute_loss(y, y_pred)
        loss_history.append(loss)

    return theta, loss_history

# 5. 모델 학습
theta, loss_history = logistic_regression_gd(X, y, lr=0.5, epochs=200)

# 6. 예측 및 시각화
X_plot = np.linspace(X.min(), X.max(), 300).reshape(-1, 1)
X_plot_b = np.c_[np.ones((X_plot.shape[0], 1)), X_plot]
y_plot = sigmoid(X_plot_b @ theta)

plt.figure(figsize=(10, 4))

# 예측 결과 시각화
plt.subplot(1, 2, 1)
plt.scatter(X, y, label='Data', alpha=0.6)
plt.plot(X_plot, y_plot, color='red', label='Logistic Regression')
plt.title('Logistic Regression (Gradient Descent)')
plt.xlabel('X')
plt.ylabel('Probability')
plt.legend()

# 손실 함수 시각화
plt.subplot(1, 2, 2)
plt.plot(loss_history)
plt.title('Loss over Epochs')
plt.xlabel('Epoch')
plt.ylabel('Log Loss')

plt.tight_layout()
plt.show()
```

# 📖 7장. 성능 평가


# [1] 분류 모델 평가의 목적

## 1. 분류 모델 평가의 필요성

* 머신러닝 분류 모델은 **입력 데이터를 주어진 범주(label)로 분류**하는 것이 목적임.
* 하지만 모델이 학습 데이터를 잘 분류한다고 해서, **새로운 데이터에도 잘 작동하는지 보장할 수 없음.**
* 따라서 모델이 실제 상황에서 얼마나 잘 작동하는지를 **정량적으로 평가**할 수 있는 지표가 필요함.

### ▶ 분류 모델 평가가 필요한 이유:

* 모델의 성능을 수치로 표현함으로써 **비교, 개선 방향 도출, 의사 결정**이 가능해짐.
* 성능이 좋지 않은 모델은 현장에 적용 시 **잘못된 예측으로 큰 피해**를 줄 수 있음.
* 특히, **의료, 보안, 자율주행 등 고위험 분야**에서는 평가 지표 선택이 매우 중요함.

---

## 2. 예측 결과의 네 가지 유형

* 분류 결과는 예측값과 실제값의 조합으로 다음의 네 가지 경우로 나뉨.

| 실제값    | 예측값    | 의미    | 약어                  |
| ------ | ------ | ----- | ------------------- |
| 1 (양성) | 1 (양성) | 참 양성  | TP (True Positive)  |
| 1 (양성) | 0 (음성) | 거짓 음성 | FN (False Negative) |
| 0 (음성) | 1 (양성) | 거짓 양성 | FP (False Positive) |
| 0 (음성) | 0 (음성) | 참 음성  | TN (True Negative)  |

* 위 결과들을 이용해 다양한 **성능 평가 지표**를 정의할 수 있음.

---

## 3. 오차 행렬 (Confusion Matrix)

* 네 가지 결과를 **2×2 행렬**로 표현한 것이 오차 행렬임.

|             | 예측 Positive | 예측 Negative |
| ----------- | ----------- | ----------- |
| 실제 Positive | TP          | FN          |
| 실제 Negative | FP          | TN          |

* 이 행렬을 통해 각 지표들을 다음과 같이 계산할 수 있음.

---

## 4. 오차 행렬의 해석 예시

&gt; 예: 암 진단 모델의 예측 결과

|          | 예측: 암 있음 | 예측: 암 없음 |
| -------- | -------- | -------- |
| 실제: 암 있음 | 90 (TP)  | 10 (FN)  |
| 실제: 암 없음 | 30 (FP)  | 870 (TN) |

* 정확도 = (TP + TN) / 전체 = (90 + 870) / 1000 = 0.96
* 정밀도 = TP / (TP + FP) = 90 / (90 + 30) = 0.75
* 재현율 = TP / (TP + FN) = 90 / (90 + 10) = 0.90

→ 암 환자를 놓치는 비율(FN)이 중요한 경우, **재현율이 더 중요한 지표**임.

---

## 5. 분류 모델 성능 평가의 핵심 질문

* 모델은 **정확한 예측을 하고 있는가?**
* 어떤 **오류가 더 위험한가?** FP vs FN
* 지표 간 **균형(trade-off)을 어떻게 조절**할 것인가?
* **사용 목적에 따라** 어떤 지표를 우선시해야 하는가?

---


# [2] 정확도와 오류율

## 1. 정확도(Accuracy)의 정의와 의미

* **정확도(Accuracy)**는 분류 모델이 **전체 데이터 중에서 얼마나 많이 맞췄는지**를 나타내는 지표임.


$$
\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}
$$

* 전체 샘플 중 **정답(TP와 TN)의 비율**을 계산함.

* 직관적으로 해석이 쉬워, 가장 널리 사용되는 평가 지표 중 하나임.


## 2. 오류율(Error Rate)의 정의와 의미

* **오류율(Error Rate)**은 모델이 잘못 예측한 비율을 의미함.

$$
\text{Error Rate} = \frac{FP + FN}{TP + TN + FP + FN}
$$

* 전체 중에서 틀린 예측의 비율이며,
  정확도와 다음의 관계를 가짐:

$$
\text{Error Rate} = 1 - \text{Accuracy}
$$


## 3. 정확도의 장점

* 직관적이고 계산이 간단함.
* 전반적인 성능을 빠르게 파악할 수 있음.
* 클래스가 **균형적인 상황**에서 효과적임.


## 4. 정확도의 한계 (클래스 불균형 문제)

* **클래스 불균형**이 존재할 경우 정확도는 **모델의 성능을 왜곡**할 수 있음.


### 예시: 클래스 불균형 상황

* 전체 1,000건 중

  * 암 환자(양성): 50건
  * 정상(음성): 950건

* 모델이 **모든 환자를 정상(0)**으로 예측한 경우:

| 실제값    | 예측값               |
| ------ | ----------------- |
| 1 (암)  | 0 (오답, FN) → 50건  |
| 0 (정상) | 0 (정답, TN) → 950건 |

* Accuracy = 950 / 1000 = **0.95**

&gt; 하지만 모델은 암 환자를 **단 1명도 맞추지 못했음.**

→ **정확도만 보면 우수해 보이나, 실제로는 무용한 모델**임.

## 5. 정확도 외 추가 지표의 필요성

* 위와 같은 한계를 극복하기 위해
  **정밀도, 재현율, F1-score** 등의 지표를 함께 고려해야 함.

* 특히, **소수 클래스의 예측이 중요한 분야(의료, 보안 등)**에서는 정확도보다 다른 지표가 더 중요함.

---


# [3] 민감도와 특이도


## 1. 민감도 (Sensitivity, Recall)의 정의

* **민감도(Sensitivity, Recall)**는 실제 양성(True Positive + False Negative) 중에서 **모델이 양성이라고 맞춘 비율**을 의미함.

$$
\text{Sensitivity} = \text{Recall} = \frac{TP}{TP + FN}
$$

* 질병 진단, 보안 경보 등 **양성(Positive)을 놓치면 안 되는 경우**에 매우 중요한 지표임.



### 예: 암 진단 모델에서의 민감도

| 실제 암 | 예측 암                     |
| ---- | ------------------------ |
| 100명 | 90명 검출 (TP), 10명 놓침 (FN) |

$$
\text{Recall} = \frac{90}{90 + 10} = 0.90
$$

→ 민감도 90%는 암 환자 중 90%를 찾아냈다는 의미임.



## 2. 특이도 (Specificity)의 정의

* **특이도(Specificity)**는 실제 음성(TN + FP) 중에서 **모델이 음성이라고 맞춘 비율**을 의미함.

$$
\text{Specificity} = \frac{TN}{TN + FP}
$$

* 즉, **정상인 중에서 정상이라고 판단한 비율**임.

* **불필요한 양성 경고(False Alarm)를 줄이는 데 중요함.**


### 예: 특이도 계산

| 실제 정상 | 예측 정상                     |
| ----- | ------------------------- |
| 900명  | 810명 검출 (TN), 90명 오진 (FP) |

$$
\text{Specificity} = \frac{810}{810 + 90} = 0.90
$$

→ 특이도 90%는 정상인 중 90%는 정확히 정상으로 판별했음을 의미함.


## 3. 민감도와 특이도의 관계

* 둘 다 **이진 분류의 중요한 지표**임.
* 하지만 **Trade-off** 관계를 가짐:

  * 민감도를 높이면 FP가 증가할 수 있어 특이도는 낮아질 수 있음.
  * 특이도를 높이면 FN이 늘어 민감도는 낮아질 수 있음.

| 상황          | 민감도 | 특이도 |
| ----------- | --- | --- |
| 엄격한 암 진단 모델 | 높음  | 낮음  |
| 스팸 필터       | 낮음  | 높음  |

---

## 4. 민감도 vs 정밀도: 비교

| 항목    | 민감도 (Recall)   | 정밀도 (Precision) |
| ----- | -------------- | --------------- |
| 초점 대상 | 실제 Positive 중  | 예측 Positive 중   |
| 계산식   | TP / (TP + FN) | TP / (TP + FP)  |
| 중요 분야 | 의료 진단          | 검색, 추천 시스템      |


---

## 5. 민감도와 특이도의 활용 예시

| 분야     | 중요한 지표 | 이유               |
| ------ | ------ | ---------------- |
| 암 진단   | 민감도    | 환자를 놓치면 큰 위험 발생  |
| 스팸 필터링 | 특이도    | 정상 메일을 오탐지하면 불편함 |
| 코로나 검사 | 민감도    | 감염자 누락은 전파 위험 증가 |
| 보안 시스템 | 특이도    | 오탐지 시 경보 남발로 무시됨 |

# [4] 정밀도와 F1 점수


## 1. 정밀도 (Precision)의 정의

* **정밀도(Precision)**는 모델이 양성이라고 예측한 것 중에서 실제로 양성인 비율을 나타냄.

$$
\text{Precision} = \frac{TP}{TP + FP}
$$

* **양성으로 예측한 것 중에서 맞춘 비율**이므로, **양성 판별의 정확성**을 평가함.



### 예: 스팸 필터에서 정밀도

| 예측 스팸 | 실제 스팸              |
| ----- | ------------------ |
| 100개  | 80개 (TP), 20개 (FP) |

$$
\text{Precision} = \frac{80}{80 + 20} = 0.8
$$

→ 스팸으로 분류한 이메일 중 **80%가 진짜 스팸**이었다는 의미임.


## 2. 정밀도의 중요성

* **정밀도는 잘못된 양성 예측(FP)**을 얼마나 줄였는지 평가함.

* 특히 **FP가 치명적인 비용을 초래하는 상황**에서 중요함.

| 분야       | 정밀도 중요 이유             |
| -------- | --------------------- |
| 금융 사기 탐지 | 정상 거래를 사기로 판단 시 불편 초래 |
| 검색 엔진 결과 | 사용자가 원치 않는 결과 노출      |
| 광고 클릭 예측 | 클릭 유도 실패 시 비용 낭비 발생   |



## 3. 정밀도 vs 재현율 (Recall)

| 항목    | 정밀도 (Precision)        | 재현율 (Recall)           |
| ----- | ---------------------- | ---------------------- |
| 초점 대상 | 예측 Positive 중 맞춘 비율    | 실제 Positive 중 맞춘 비율    |
| 계산식   | TP / (TP + FP)         | TP / (TP + FN)         |
| 중요 상황 | False Positive가 민감한 경우 | False Negative가 민감한 경우 |

* 둘은 **상충하는 경우가 많음.**
  → 정밀도를 높이면 FP를 줄이려 하므로 FN이 늘 수 있음.
  → 재현율을 높이면 FN을 줄이려 하므로 FP가 늘 수 있음.


## 4. F1 점수 (F1-score)의 정의

* **F1 점수**는 정밀도와 재현율을 **조화 평균(Harmonic Mean)**으로 결합한 지표임.

$$
\text{F1 Score} = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}
$$

* 정밀도와 재현율의 **균형이 중요할 때 사용**함.
* 둘 중 하나라도 낮으면 F1 점수도 낮아짐.



### 예: Precision = 0.8, Recall = 0.6

$$
\text{F1 Score} = 2 \cdot \frac{0.8 \cdot 0.6}{0.8 + 0.6} = 2 \cdot \frac{0.48}{1.4} ≈ 0.6857
$$


## 5. F1 점수의 활용 예시

* **정밀도와 재현율 중 어느 하나에만 집중할 수 없을 때** 적절한 종합 지표임.

| 분야       | 활용 이유                         |
| -------- | ----------------------------- |
| 의료 진단    | 암 환자를 놓치면 안 되지만, 과잉 진단도 줄여야 함 |
| 문서 분류    | 관련 문서를 놓치지 않으면서도 정확하게 분류해야 함  |
| 채용 자동 필터 | 우수 지원자를 빠짐없이 찾되, 부적합자는 걸러야 함  |


## 6. F1-score vs Accuracy

| 항목      | Accuracy       | F1 Score            |
| ------- | -------------- | ------------------- |
| 초점 대상   | 전체 데이터에서 맞춘 비율 | 정밀도와 재현율의 균형        |
| 클래스 불균형 | 취약             | 강함                  |
| 계산 기준   | TP, TN 모두 포함   | TN 포함 안 됨, FP/FN 중심 |

# [5] ROC 곡선



## 1. ROC 곡선의 개념

* **ROC (Receiver Operating Characteristic) 곡선**은
  분류 모델의 **임계값(threshold)**을 바꿔가며 성능을 시각화한 곡선임.

* x축: **FPR (False Positive Rate)**

* y축: **TPR (True Positive Rate) = 민감도 (Sensitivity)**


| 용어  | 수식             | 의미           |
| --- | -------------- | ------------ |
| TPR | TP / (TP + FN) | 민감도 (Recall) |
| FPR | FP / (FP + TN) | 잘못된 양성 비율    |

---

### ▣ ROC 곡선 그리는 방법

1. 모델이 출력한 확률 또는 점수를 **내림차순 정렬**
2. 여러 임계값을 기준으로 **양성/음성 판단**
3. 각각의 임계값에서 TPR, FPR 계산
4. (FPR, TPR) 점을 연결하여 곡선 생성



## 2. ROC 곡선의 해석

* **(0,1)**에 가까울수록 성능이 좋은 모델임. → 왼쪽 위에 몰릴수록 좋은 모델
* **대각선(0,0) \~ (1,1)**은 랜덤 추측과 동일한 성능임.
* ROC 곡선이 **위로 볼록하게 휘어질수록 성능이 우수함.**


## 3. 다양한 모델의 ROC 곡선 비교

| 모델     | ROC 곡선 형태         | 해석                    |
| ------ | ----------------- | --------------------- |
| 완벽한 모델 | (0,1)에 가까운 곡선     | TPR 100%, FPR 0% 가능   |
| 좋은 모델  | 대각선 위에서 위로 볼록한 곡선 | 대부분의 임계값에서 TPR 높음     |
| 무작위 모델 | 대각선 선형            | TPR = FPR (랜덤 추측과 동일) |
| 나쁜 모델  | 대각선 아래 (뒤집힌 ROC)  | 양/음성 예측을 뒤집으면 개선됨     |

---

## 4. 임계값(Threshold)에 따른 변화

* 대부분의 분류 모델은 예측 결과로 **확률값(0\~1)**을 출력함.
* 기본적으로 0.5 이상이면 양성으로 판단하지만,
  임계값을 조절하면 **정밀도와 재현율**의 균형을 바꿀 수 있음.


### 임계값이 낮을수록:

* 양성으로 판단하는 기준이 느슨해짐
* **TP와 FP가 증가 → TPR 증가, FPR도 증가**


### 임계값이 높을수록:

* 엄격하게 양성으로 판단함
* **FP는 줄지만 FN이 증가 → TPR은 줄고, FPR도 줄어듦**

## 5. ROC 곡선의 장단점

| 항목     | 장점                        | 단점                        |
| ------ | ------------------------- | ------------------------- |
| 해석력    | 다양한 임계값에서 성능을 시각적으로 확인 가능 | 실제 응용에 적합한 임계값은 제시하지 않음   |
| 클래스 영향 | 클래스 불균형의 영향을 덜 받음         | 적중률(Precision)에 대한 정보는 없음 |

→ 따라서 **Precision-Recall Curve**와 함께 보는 것도 중요함.

---
# [6] AUC (Area Under Curve)



## 1. AUC의 정의

* **AUC (Area Under the Curve)**는 **ROC 곡선 아래 면적**을 수치화한 값임.
* 곡선의 아래 면적이 넓을수록, 즉 ROC 곡선이 **왼쪽 위에 가까울수록** 성능이 좋다고 판단함.

$$
\text{AUC} = \int_{0}^{1} TPR(FPR) \, dFPR
$$

→ 실제로는 면적을 수치적으로 근사하여 계산함.



## 2. AUC의 값 범위 및 해석

| AUC 값 범위   | 성능 수준     | 해석                        |
| ---------- | --------- | ------------------------- |
| 1.0        | 완벽한 모델    | 모든 Positive를 정확히 예측함      |
| 0.9 \~ 1.0 | 매우 우수     | 거의 완벽하게 구분 가능             |
| 0.8 \~ 0.9 | 우수        | 일반적으로 좋은 모델               |
| 0.7 \~ 0.8 | 보통        | 개선의 여지가 있음                |
| 0.6 \~ 0.7 | 낮은 성능     | 비교적 낮은 분류력                |
| 0.5        | 무작위 예측 수준 | Positive와 Negative를 구분 못함 |
| 0.0 \~ 0.5 | 반대로 예측함   | 모델 출력을 뒤집으면 더 나은 성능임      |



## 3. AUC의 장점과 한계

### ▣ 장점

* **모델 전체 성능을 하나의 값으로 요약**할 수 있음
* 임계값 설정 없이 비교 가능
* 클래스 불균형에도 **상대적으로 강건함**


### ▣ 한계

* 실제 운영에서는 **임계값을 설정해야 하므로**,
  AUC가 높아도 **현실적인 Threshold에서 성능이 나쁠 수 있음**
* 실제 응용에서 필요한 **Precision, Recall 지표가 직접 반영되지 않음**

# [8] 성능 지표 선택 전략


## 1. 왜 전략적으로 지표를 선택해야 하는가?

* 분류 모델의 성능은 다양한 **지표(accuracy, precision, recall, F1, AUC 등)**으로 평가할 수 있음.
* 그러나 **모든 문제에 하나의 지표가 적합한 것은 아님.**
* **문제의 특성, 비용, 위험성**에 따라 적절한 지표를 선택하는 것이 중요함.



## 2. 분야별 지표 선택 기준

| 분야        | 주요 지표                 | 이유                   |
| --------- | --------------------- | -------------------- |
| 의료 진단     | Recall (민감도), F1, AUC   | 병을 놓치면 위험(FN 최소화)    |
| 스팸 필터링    | Precision (정밀도)       | 정상 메일 오탐지(FP) 최소화    |
| 광고 추천     | Precision, ROC AUC    | 클릭 유도 정확성 중요         |
| 이상 탐지     | Recall, AUC           | 이상을 놓치면 치명적          |
| 금융 사기 탐지  | F1-score, AUC         | 사기 탐지 균형 중요          |
| 검색 시스템    | Precision\@K, MAP     | 최상위 결과의 정확성          |
| 채용 자동 필터링 | Precision, Recall, F1 | 우수 인재 누락 방지 및 오필터 방지 |


## 3. 클래스 불균형 문제 고려

* 예: 암 환자 1%, 정상인 99%일 때

  * 모델이 모두 정상으로 예측해도 **정확도는 99%**
  * 하지만 **Recall = 0** → 암 환자를 하나도 못 찾음

→ 이 경우는 정확도보다 **Recall, AUC** 등을 우선 고려해야 함.



## 4. Threshold 조절 전략

* 확률 기반 분류 모델은 **임계값(threshold)**을 조절할 수 있음.

| 임계값   | 효과                    |
| ----- | --------------------- |
| 낮게 설정 | 재현율 ↑, 정밀도 ↓ (검출 중심)  |
| 높게 설정 | 정밀도 ↑, 재현율 ↓ (정확성 중심) |

→ 실제 서비스에서는 **운영 목적에 따라 임계값을 최적화**하는 과정이 필요함.


## 5. 실제 사례 예시

### ▣ 의료 분야

* 문제: 폐암 진단
* 요구: **암 환자 놓치면 안 됨** → Recall 중요
* 전략:

  * Recall &gt; 0.95 확보
  * Precision은 다소 낮아도 괜찮음
  * AUC도 함께 참고



### ▣ 이메일 스팸 필터

* 문제: 스팸 이메일 분류
* 요구: **정상 메일을 스팸으로 분류하면 문제** → Precision 중요
* 전략:

  * Precision &gt; 0.98
  * Recall은 약간 낮아도 괜찮음
  * F1-score는 참고 지표로 활용



## 6. 성능 평가 기준 설정 순서

1. **문제 정의**: 어떤 오류가 더 치명적인가?
2. **비용 고려**: FN vs FP 중 비용이 큰 쪽은?
3. **지표 선택**: Accuracy, Precision, Recall, F1, AUC 등
4. **임계값 조절**: 운영 목적에 맞게 threshold 튜닝
5. **종합 판단**: 상황별 복수 지표를 함께 사용

# 📘 [1] k-최근접 이웃 알고리즘 (k-Nearest Neighbors, kNN)


## 1. 개념

**k-최근접 이웃 알고리즘(kNN)**은 가장 단순하면서도 강력한 **비모수(non-parametric)** 지도 학습 알고리즘 중 하나입니다.

* 주어진 입력 데이터에 대해 **가장 가까운 k개의 이웃**을 찾고,
* 그 이웃들의 레이블을 바탕으로 예측을 수행합니다.


## 2. 원리

1. **훈련 단계 (Training)**

   * 특별한 학습 과정이 없습니다. 모든 학습 데이터를 **기억**해둡니다.
   * 즉, **기억 기반 모델(Memory-based model)** 또는 **Lazy Learning**이라고 합니다.

2. **예측 단계 (Prediction)**
   새로운 데이터 포인트 $x$가 들어오면:

   * 학습 데이터 전체와의 거리를 계산합니다.
   * 거리 기준으로 가장 가까운 **k개의 데이터**를 선택합니다.
   * **분류 문제**:

     * 다수결 투표(Majority Voting)를 통해 가장 많이 등장한 클래스 선택
   * **회귀 문제**:

     * k개의 평균을 사용해 예측


## 3. 거리 계산

가장 널리 쓰이는 거리 함수는 **유클리드 거리(Euclidean distance)**입니다:

$$
d(x, x_i) = \sqrt{ \sum_{j=1}^{n} (x_j - x_{ij})^2 }
$$

그 외에도:

* 맨해튼 거리: $\sum |x_j - x_{ij}|$
* 코사인 거리: $1 - \cos(\theta)$

---

## 4. 하이퍼파라미터

| 하이퍼파라미터      | 설명                                             |
| ------------ | ---------------------------------------------- |
| **k** (이웃 수) | 너무 작으면 과적합, 너무 크면 과소적합                         |
| **거리 척도**    | 유클리드, 맨해튼, 코사인 등                               |
| **가중치 방식**   | 이웃 거리에 따라 가중치를 둘 수도 있음 (`uniform`, `distance`) |

---

## 5. 장점과 단점

| 장점                    | 단점                            |
| --------------------- | ----------------------------- |
| 구현이 간단함               | 계산 비용이 큼 (예측 시 전체 데이터와 거리 계산) |
| 비모수 모델 (데이터 분포 가정 없음) | 고차원에서는 성능 저하 (차원의 저주)         |
| 다중 클래스/회귀 모두 가능       | 훈련 데이터가 많을수록 속도 느림            |

# 📘 [2] 서포트 벡터 머신(Support Vector Machine, SVM)

## 1. 역사적 배경

* **1992년**: 러시아 출신의 **Vladimir Vapnik**과 **Alexey Chervonenkis**가 이론적 기초인 **VC 차원**(Vapnik–Chervonenkis dimension)과 **구간 리스크 최소화** 개념을 발표했습니다.
* **1995년**: Vapnik과 Cortes가 현대적 의미의 SVM 알고리즘을 공식화함. 이 논문은 "Support-Vector Networks"라는 제목으로 발표되며, **마진 최대화**와 \*\*커널 트릭(Kernel Trick)\*\*을 통해 비선형 분류까지 확장됨.
* **2000년대**: Bioinformatics, 문서 분류, 이미지 인식 등 다양한 분야에서 **고차원 소규모 데이터**에 강한 분류기로 널리 활용됨.

## 2. SVM의 핵심 아이디어

* **마진 최대화**: 클래스를 구분하는 **결정 경계**(Decision Boundary) 중, 가장 \*\*넓은 여백(Margin)\*\*을 가지는 선형 결정 경계를 찾음.
* **서포트 벡터**: 결정 경계에 가장 가까운 데이터 포인트.
* **커널 기법**: 비선형 데이터를 고차원으로 매핑하여 선형 분리 가능하게 만드는 방법.


## 3. 수학적 수식

### 목적: 최대 마진 분리 초평면 찾기

선형 SVM의 목적은 다음과 같은 초평면을 찾는 것입니다.

$$
\mathbf{w}^\top \mathbf{x} + b = 0
$$

클래스는 다음 조건을 만족해야 합니다:

$$
y_i (\mathbf{w}^\top \mathbf{x}_i + b) \geq 1 \quad \forall i
$$

### 최적화 문제

$$
\min_{\mathbf{w}, b} \frac{1}{2} \|\mathbf{w}\|^2 \quad \text{subject to} \quad y_i(\mathbf{w}^\top \mathbf{x}_i + b) \geq 1
$$

이 문제는 **Convex Quadratic Programming** 형태이며, Lagrange multiplier 기법으로 최적화됩니다.

### 🔄 비선형 SVM (Kernel Trick)

$$
\phi(\mathbf{x})^\top \phi(\mathbf{x'}) = K(\mathbf{x}, \mathbf{x'})
$$

* 대표 커널: 선형(linear), 다항식(polynomial), RBF(Gaussian), 시그모이드(sigmoid)

# 📘 [3] 의사결정나무 (Decision Tree) 알고리즘

## 1. 역사적 배경

* **1960년대**: 통계학 분야에서 분류 및 회귀를 위한 트리 기반 모델이 연구되기 시작함.
* **1986년**: **J. Ross Quinlan**이 발표한 **ID3(Iterative Dichotomiser 3)** 알고리즘이 널리 주목받으며 의사결정나무 알고리즘의 표준이 됨.
* 이후 **C4.5**(1993), **CART(Classification and Regression Tree)**(Breiman et al., 1984) 등 다양한 버전이 개발됨.
* 현재는 **Random Forest**, **XGBoost** 등의 앙상블 기반 트리 모델의 기본 단위로도 사용됨.


## 2. 이론적 개념

### 기본 아이디어

의사결정나무는 데이터를 **특성(feature)**에 따라 분할(split)하여 **트리 형태로 분류** 또는 **예측**을 수행합니다.

* 루트 노드: 전체 데이터
* 내부 노드: 특성 기준으로 데이터를 분할
* 리프 노드: 최종 예측 결과(클래스 or 수치 값)


### 분할 기준 (지니, 엔트로피, 분산)

#### (1) **분류(Classification)** 문제:

* **지니 불순도(Gini Impurity)**

  $$
  Gini = 1 - \sum_{i=1}^n p_i^2
  $$
* **엔트로피(Entropy)**

  $$
  Entropy = - \sum_{i=1}^n p_i \log_2 p_i
  $$

→ 두 기준 모두 불순도(혼합도)를 최소화하도록 분할합니다.

#### (2) **회귀(Regression)** 문제:

* **MSE (Mean Squared Error)** 또는 **MAE**를 사용하여 분할

3. 가장 불순도를 많이 줄이는 특성으로 분할
4. 리프 노드가 될 조건(순도가 높거나 최대 깊이 도달 등)까지 반복

### 핵심 개념

**Random Forest는 여러 개의 Decision Tree를 훈련시킨 뒤, 각 트리의 결과를 종합하여 최종 예측을 수행하는 앙상블 학습 기법입니다.**

---

### 🔷 Bagging: Bootstrap Aggregating

* **Bootstrap**: 데이터셋에서 **중복 허용 무작위 샘플링**으로 N개의 학습용 샘플 생성
* **Aggregating**: 각각의 모델 결과를 평균(회귀) 또는 투표(분류)를 통해 종합

---

### 🔷 Randomness (무작위성) 도입

1. **데이터 샘플 무작위 선택** (Bagging)
2. **각 노드에서 특성(feature) 무작위 선택** (예: √p 개 중 최적 분할 특성 선택)

이 두 가지 무작위성으로 인해 **트리 간 상관성 감소**, 결과적으로 **앙상블 효과 향상** 및 **과적합 감소** 효과를 얻음.

---

### 🔷 알고리즘 동작 과정

1. **T개의 결정 트리 생성**

   * 각 트리는 Bootstrapping된 데이터로 학습
2. **각 트리에서 무작위 피처 서브셋 선택**
3. **각 트리의 결과 예측**

   * 분류: **다수결 투표(Majority Voting)**
   * 회귀: **평균값 산출(Averaging)**


### 요약 다이어그램

# 📘 [5] XGBoost (eXtreme Gradient Boosting) 알고리즘

## **1. 역사적 배경**

### (1) 부스팅 알고리즘의 흐름

| 연도     | 알고리즘                         | 설명                                   |
| ------ | ---------------------------- | ------------------------------------ |
| 1990년대 | AdaBoost                     | 가장 처음 널리 사용된 부스팅 모델. 가중치 기반 분류기 조합   |
| 2000년대 | Gradient Boosting (GBM)      | 잔차(residual)에 대한 기울기를 기반으로 약한 학습기 추가 |
| 2014년  | **XGBoost** (by Tianqi Chen) | GBM의 단점 보완 → 속도, 성능, 병렬성에서 혁신적 개선    |

&gt; 📝 참고: XGBoost는 **Kaggle** 등의 머신러닝 경진대회에서 압도적 성능을 보여주며 대중적으로 널리 퍼졌습니다.

---

## **2. 이론적 배경**

### (1) Gradient Boosting의 기본 개념

* 목적: 여러 개의 **약한 학습기(weak learner, 보통은 결정 트리)** 를 순차적으로 학습하여 점점 예측력을 높임.
* 방식: 이전 모델이 만든 **오차(잔차)** 를 예측하도록 다음 모델을 훈련

#### 기본 수식

모델의 예측값을 $F(x)$라 할 때, 이를 반복적으로 갱신:

$$
F_{m}(x) = F_{m-1}(x) + \gamma h_m(x)
$$

* $h_m(x)$: 현재 단계에서 학습하는 새로운 트리
* $\gamma$: 학습률 (learning rate)

---

### (2) XGBoost의 핵심 아이디어

XGBoost는 기존 Gradient Boosting의 약점을 보완하면서 **속도와 정확도를 극대화**하는 데 초점을 맞춘 알고리즘입니다.

#### 🔧 개선 요소

| 요소              | 설명                          |
| --------------- | --------------------------- |
| **정규화 추가**      | 과적합 방지를 위해 **L1/L2** 정규화 포함 |
| **병렬 트리 생성**    | 트리의 노드를 병렬로 분할하여 연산 속도 향상   |
| **히스토그램 기반 학습** | 연속값을 이산화하여 학습 효율 향상         |
| **스파스 데이터 처리**  | 결측값을 자동 감지하여 최적 분기 생성       |
| **Cache 최적화**   | 내부 메모리 접근 최적화로 빠른 연산        |

---

### (3) XGBoost의 목적 함수 (Objective Function)

XGBoost는 목적 함수 $Obj$를 다음과 같이 정의합니다:

$$
Obj = \sum_{i=1}^{n} l(y_i, \hat{y}_i) + \sum_{k=1}^{K} \Omega(f_k)
$$

* $l$: 손실 함수 (예: MSE, Log loss 등)
* $\Omega(f_k)$: 복잡도 패널티 (트리의 깊이, 노드 수 등)

#### 복잡도 항

$$
\Omega(f) = \gamma T + \frac{1}{2} \lambda \sum_{j=1}^{T} w_j^2
$$

* $T$: 리프 노드의 수
* $w_j$: 리프 노드의 출력 값
* $\gamma$, $\lambda$: 정규화 계수

---

### (4) XGBoost 주요 하이퍼파라미터

| 파라미터                      | 설명                |
| ------------------------- | ----------------- |
| `n_estimators`            | 생성할 트리 수          |
| `max_depth`               | 트리 최대 깊이          |
| `learning_rate`           | 각 단계의 기여율         |
| `subsample`               | 훈련 샘플 비율 (과적합 방지) |
| `colsample_bytree`        | 트리마다 사용할 특성 비율    |
| `reg_alpha`, `reg_lambda` | L1, L2 정규화 계수     |

# 9장. 군집화

# [1] 군집화(Clustering) 개요

## 1. 군집화란?

* 군집화(clustering)란 **데이터를 유사한 특성을 가진 그룹(군집, cluster)으로 나누는 비지도 학습** 기법임.
* 데이터에 레이블(label, 정답)이 없는 경우에 사용함.
* 각 군집(cluster)은 데이터 간 **내부 응집도(intra-cluster similarity)는 높고, 군집 간 분리도(inter-cluster dissimilarity)는 높도록** 구성됨.

### ● 정의

&gt; 클러스터링은 입력된 데이터 샘플들을 비슷한 특성을 가진 그룹으로 자동 분류하는 과정임. 이때 데이터 간의 유사성(similarity) 또는 거리(distance)를 기준으로 함.

---

## 2. 지도학습 vs 비지도학습 비교

| 항목      | 지도학습(Supervised)                          | 비지도학습(Unsupervised)                              |
| ------- | ----------------------------------------- | ------------------------------------------------ |
| 입력 데이터  | 입력 + 정답(label)                            | 입력만 존재 (label 없음)                                |
| 목적      | 정답을 맞추는 분류/회귀                             | 숨겨진 구조/패턴 탐색                                     |
| 대표 기법   | 분류(Classification), 회귀(Regression)        | 군집화(Clustering), 차원 축소(Dimensionality Reduction) |
| 예시 알고리즘 | Logistic Regression, SVM, Random Forest 등 | K-means, DBSCAN, PCA 등                           |

---

## 3. 군집화의 주요 응용 분야

| 분야       | 예시 응용                 |
| -------- | --------------------- |
| 마케팅/비즈니스 | 고객 세분화, 추천 시스템        |
| 의료       | 환자 유형 분류, 질병 패턴 분류    |
| 영상 처리    | 이미지 분할, 객체 검출 전처리     |
| 자연어 처리   | 문서 주제 분류, 토픽 모델링      |
| 이상 탐지    | 비정상 트랜잭션 탐지, 센서 고장 감지 |

---

## 4. 군집화에서 사용하는 거리 측정법

* 군집화에서는 데이터 간의 **거리(distance)** 또는 **유사도(similarity)** 를 기반으로 군집을 구성함.
* 자주 사용되는 거리 지표는 다음과 같음:

| 거리/유사도 지표 | 설명                    | 수식 예시            |         |   |       |   |
| --------- | --------------------- | ---------------- | ------- | - | ----- | - |
| 유클리디안 거리  | 가장 일반적인 거리 계산         | √(∑(xi - yi)²)   |         |   |       |   |
| 맨해튼 거리    | 절댓값 거리 합              | ∑                | xi - yi |   |       |   |
| 코사인 유사도   | 두 벡터의 방향이 얼마나 유사한지 측정 | (X·Y) / (‖X‖‖Y‖) |         |   |       |   |
| 자카드 유사도   | 집합 간 유사성              |                  | A ∩ B   | / | A ∪ B |   |

---

## 5. 클러스터의 품질 조건

군집화 결과의 품질은 다음 조건들을 만족해야 함:

* **내부 응집도(Intra-cluster cohesion)**: 같은 클러스터 내의 데이터는 서로 가깝거나 유사해야 함.
* **군집 간 분리도(Inter-cluster separation)**: 다른 클러스터 간 데이터는 멀거나 이질적이어야 함.

# [2] 군집화의 평가 지표와 클러스터 수 결정

## 1. 군집화 결과 평가 개요

* 군집화는 **비지도학습**이기 때문에 일반적으로 정답(label)이 존재하지 않음.
* 따라서 평가 지표는 **내부 평가 지표**와 **외부 평가 지표**로 구분됨.

---

## 2. 내부 평가 지표 (Internal Evaluation Metrics)

&gt; 정답 레이블 없이 군집화 결과만으로 군집 품질을 평가함.
&gt; 군집 간 거리와 군집 내 거리를 기준으로 함.

| 평가 지표                     | 설명                            | 해석 기준       |
| ------------------------- | ----------------------------- | ----------- |
| 실루엣 점수 (Silhouette Score) | 한 샘플의 클러스터 응집도와 분리도를 동시에 고려   | 1에 가까울수록 좋음 |
| Davies-Bouldin Index      | 군집 내 분산과 군집 간 거리의 비율을 기반으로 측정 | 값이 작을수록 좋음  |
| Calinski-Harabasz Index   | 군집 간 분산 / 군집 내 분산 비율          | 값이 클수록 좋음   |

### ● 실루엣 점수 수식:

$$
s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}
$$

* $a(i)$: 같은 클러스터 내 평균 거리
* $b(i)$: 가장 가까운 다른 클러스터와의 평균 거리
* $s(i) \in [-1, 1]$: 1에 가까울수록 잘 군집됨

---

## 3. 외부 평가 지표 (External Evaluation Metrics)

&gt; 정답 레이블이 존재할 때 사용. 군집화 결과와 실제 레이블의 일치 정도를 평가함.

| 평가 지표                               | 설명                             |
| ----------------------------------- | ------------------------------ |
| Adjusted Rand Index (ARI)           | 랜덤 클러스터링 대비 얼마나 유사한 결과를 내는지 평가 |
| Normalized Mutual Information (NMI) | 정보 이론 기반 클러스터링과 레이블 간의 유사도 측정  |
| Fowlkes-Mallows Index               | 정답 클러스터와 예측 클러스터 간 일치율 평가      |

---

## 4. 클러스터 수 결정 방법

군집화에서 적절한 클러스터 수 $k$ 를 찾는 것이 매우 중요함. 이를 위해 다음과 같은 방법들을 사용함.

### (1) 엘보우(Elbow) 방법

* 군집 수에 따른 **SSE (Sum of Squared Errors)** 를 계산하여 **급격한 감소가 꺾이는 지점**(엘보우)을 선택함.

&gt; $$
&gt; $$

SSE = \sum\_{i=1}^{k} \sum\_{x \in C\_i} |x - \mu\_i|^2
]

* 그래프에서 SSE가 급격히 감소하다가 완만해지는 ‘팔꿈치’ 지점을 최적 k로 판단함.

### (2) 실루엣 분석

* 여러 k에 대해 실루엣 점수를 계산하여, **점수가 가장 높은 k**를 선택함.

---

## 5. 평가 예시 시각화

* 아래는 `make_blobs` 데이터에 대해 K=2\~6까지 실루엣 점수와 엘보우 지표를 시각화한 예시임.

```python
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score
import matplotlib.pyplot as plt

X, _ = make_blobs(n_samples=500, centers=4, cluster_std=1.0)

sse = []
sil_scores = []
k_range = range(2, 7)

for k in k_range:
    model = KMeans(n_clusters=k, random_state=42).fit(X)
    sse.append(model.inertia_)
    sil_scores.append(silhouette_score(X, model.labels_))

plt.figure(figsize=(12, 5))
plt.subplot(1, 2, 1)
plt.plot(k_range, sse, marker='o')
plt.title("Elbow Method (SSE)")
plt.xlabel("Number of clusters")
plt.ylabel("SSE")

plt.subplot(1, 2, 2)
plt.plot(k_range, sil_scores, marker='o', color='green')
plt.title("Silhouette Score")
plt.xlabel("Number of clusters")
plt.ylabel("Score")

plt.tight_layout()
plt.show()
```

# [3] 대표적인 군집화 알고리즘



## 1. K-means 알고리즘

### ● 개념

* 데이터를 **사전에 지정한 개수(k)의 중심점(centroid)** 주위로 군집화하는 알고리즘임.
* 각 데이터는 가장 가까운 중심점에 할당되며, 중심점은 클러스터의 평균값으로 반복적으로 갱신됨.

### ● 알고리즘 수행 과정

1. 클러스터 수 $k$ 설정
2. 무작위로 $k$개의 초기 중심점 선택
3. 각 데이터 포인트를 가장 가까운 중심점에 할당
4. 클러스터별 중심점 재계산
5. 중심점 이동이 없을 때까지 3\~4단계 반복

### ● 수식

* 거리 계산: 유클리디안 거리
* 중심점 재계산:

$$
\mu_k = \frac{1}{|C_k|} \sum_{x_i \in C_k} x_i
$$

### ● 장점과 단점

| 장점                   | 단점                     |
| -------------------- | ---------------------- |
| 구현이 간단하고 계산이 빠름      | k 값 사전 지정 필요           |
| 대규모 데이터에 잘 작동        | 이상치(outlier)에 민감함      |
| 구형(cluster)의 데이터에 적합 | 복잡한 분포나 밀도 차이 데이터에 부적합 |

---

## 2. 계층적 군집화 (Hierarchical Clustering)

### ● 개념

* 모든 데이터를 개별 클러스터로 시작하여 점차 병합하거나, 전체를 시작으로 나누는 방식으로 트리를 형성함.
* 결과는 **덴드로그램(Dendrogram)** 으로 시각화됨.

### ● 유형

| 유형                 | 설명                      |
| ------------------ | ----------------------- |
| 병합형(Agglomerative) | bottom-up 방식, 가장 많이 사용됨 |
| 분할형(Divisive)      | top-down 방식, 연산 비용 큼    |

### ● 거리 계산 방식

* 단일 연결(Single Linkage): 두 군집 간 최단 거리
* 완전 연결(Complete Linkage): 두 군집 간 최장 거리
* 평균 연결(Average Linkage): 두 군집 간 평균 거리

### ● 장점과 단점

| 장점                   | 단점               |
| -------------------- | ---------------- |
| 클러스터 수 사전 지정 불필요     | 계산 비용이 큼 (O(n²)) |
| 덴드로그램으로 군집 구조 시각화 가능 | 노이즈에 민감할 수 있음    |

---

## 3. DBSCAN (Density-Based Spatial Clustering of Applications with Noise)

### ● 개념

* 밀도(density)를 기준으로 클러스터를 형성하며, **노이즈나 이상치 탐지에 강함**.
* 밀도 중심으로 연결된 점들을 클러스터로 묶음.

### ● 핵심 파라미터

* `eps`: 반경 거리
* `min_samples`: 클러스터를 이루기 위한 최소 샘플 수

### ● 주요 용어

| 용어                 | 정의                               |
| ------------------ | -------------------------------- |
| 핵심 포인트(core point) | 반경 내 `min_samples` 이상의 점이 있는 포인트 |
| 경계점(border point)  | 핵심점의 이웃이지만 자신은 핵심이 아닌 포인트        |
| 잡음(noise point)    | 어떤 클러스터에도 속하지 않는 점               |

### ● 장점과 단점

| 장점                  | 단점                        |
| ------------------- | ------------------------- |
| 클러스터 수 자동 결정 가능     | eps, min\_samples 설정에 민감함 |
| 이상치 탐지에 강함          | 차원 수가 높을수록 성능 저하됨         |
| 불규칙한 모양의 클러스터 탐지 가능 | 밀도가 불균일한 데이터에는 부적합할 수 있음  |

---

## 4. 알고리즘 비교 요약표

| 알고리즘    | 클러스터 수 필요 | 이상치 처리 | 클러스터 모양   | 계산 효율성 | 시각화 도구 |
| ------- | --------- | ------ | --------- | ------ | ------ |
| K-means | 필요        | 민감함    | 구형        | 빠름     | X      |
| 계층적     | 불필요       | 보통     | 다양한       | 느림     | 덴드로그램  |
| DBSCAN  | 불필요       | 강함     | 비선형 구조 가능 | 중간     | X      |

# [4] K-means 군집화 실습


* `make_blobs` 데이터를 대상으로 **K-means 군집화**를 수행하고
  클러스터링 결과를 시각화함.
* 클러스터 수 변화에 따른 결과와 **엘보우 기법**을 통해 적정 k를 분석함.



```python
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans
import matplotlib.pyplot as plt

# 데이터 생성
X, _ = make_blobs(n_samples=300, centers=4, cluster_std=0.7, random_state=0)

# KMeans 모델 훈련
kmeans = KMeans(n_clusters=4, random_state=0)
kmeans.fit(X)

# 결과 시각화
plt.scatter(X[:, 0], X[:, 1], c=kmeans.labels_, cmap='viridis', s=50)
plt.scatter(kmeans.cluster_centers_[:, 0], kmeans.cluster_centers_[:, 1],
            c='red', marker='X', s=200, label='Centroids')
plt.title("K-means Clustering 결과")
plt.xlabel("X1")
plt.ylabel("X2")
plt.legend()
plt.grid(True)
plt.show()
```

---

```python
# 클러스터 수 변화 실험
for k in range(2, 6):
    kmeans = KMeans(n_clusters=k, random_state=0).fit(X)
    plt.figure()
    plt.scatter(X[:, 0], X[:, 1], c=kmeans.labels_, cmap='plasma')
    plt.scatter(kmeans.cluster_centers_[:, 0], kmeans.cluster_centers_[:, 1],
                c='red', marker='X', s=200)
    plt.title(f"K-means (k={k})")
    plt.grid(True)
    plt.show()
```

---
```python
#  엘보우 방법으로 최적 k 찾기 &amp; 실루엣 점수 계산
from sklearn.metrics import silhouette_score
sse = []
K = range(2, 11) # shilhouette_score는 k &gt;= 2 이어야 함
silhouette_scores = []
for k in K:
    kmeans = KMeans(n_clusters=k, random_state=0)
    kmeans.fit(X)
    score = silhouette_score(X, kmeans.labels_) 
    silhouette_scores.append(score )
    sse.append(kmeans.inertia_)

print( silhouette_scores)
plt.figure(figsize=(12, 6))
plt.subplot(1, 2, 1)
plt.plot(K, sse, marker='o')
plt.xlabel('Number of Clusters (k)')
plt.ylabel('SSE (Sum of Squared Errors)')
plt.title('Searching k by Elbow method')
plt.grid(True)

plt.subplot(1, 2, 2)
plt.plot(K, silhouette_scores, marker='o')
plt.xlabel('Number of Clusters (k)')
plt.ylabel('Silhouette Score')
plt.title('Searching k by Silhouette Score')
plt.show()
```


| 함수명                           | 설명                  | 주요 파라미터                              |
| ----------------------------- | ------------------- | ------------------------------------ |
| `KMeans(n_clusters=k)`        | K-means 클러스터링 수행    | `n_clusters`, `init`, `random_state` |
| `.fit(X)`                     | 데이터 학습              | X: 입력 데이터                            |
| `.labels_`                    | 각 데이터에 할당된 클러스터 번호  | 없음                                   |
| `.cluster_centers_`           | 각 클러스터 중심좌표 반환      | 없음                                   |
| `.inertia_`                   | 클러스터 내 거리 제곱합 (SSE) | 없음                                   |
| `silhouette_score(X, labels)` | 실루엣 점수 계산           | `X`, `labels`                        |

- Note that Silhouette Coefficient is only defined if number of labels
is 2 &lt;= n_labels &lt;= n_samples - 1. This function returns the mean Silhouette Coefficient over all samples. The best value is 1 and the worst value is -1. Values near 0 indicate
overlapping clusters. Negative values generally indicate that a sample has
been assigned to the wrong cluster, as a different cluster is more similar.

# [6] DBSCAN 실습


## 1. DBSCAN 개요 및 실습 목표

* DBSCAN은 **밀도 기반 군집화(Density-Based Spatial Clustering)** 방법임.
* 클러스터 수를 지정하지 않아도 되고, **복잡한 모양의 군집**을 탐지할 수 있음.
* **노이즈나 이상치 탐지에 효과적**임.

### ● 핵심 파라미터

* `eps`: 반경 거리 (이웃으로 간주할 최대 거리)
* `min_samples`: 최소 이웃 수 (핵심 점이 되기 위한 최소 포인트 수)

---

## 2. `make_moons`를 활용한 실습

```python
from sklearn.datasets import make_moons
from sklearn.cluster import DBSCAN
import matplotlib.pyplot as plt

# 데이터 생성
X, _ = make_moons(n_samples=300, noise=0.07, random_state=42)

# DBSCAN 클러스터링
dbscan = DBSCAN(eps=0.2, min_samples=5)
dbscan.fit(X)

# 시각화
plt.scatter(X[:, 0], X[:, 1], c=dbscan.labels_, cmap='plasma', s=50)
plt.title("DBSCAN (make_moons)")
plt.xlabel("X1")
plt.ylabel("X2")
plt.grid(True)
plt.show()
```
---

## 3. 파라미터 변화 실험 및  이상치 탐지 확인

* DBSCAN에서는 **클러스터에 속하지 않는 점들에 대해 레이블을 -1로 부여**함.
* 아래 코드를 통해 **이상치의 수와 위치**를 확인할 수 있음.
* `eps` 값이 작으면 군집이 잘게 나뉘고 이상치가 많아짐.
* `min_samples`가 크면 더 조밀한 군집만 인정됨.

```python
for eps_val in [0.1, 0.2, 0.3, 0.5]:
    dbscan = DBSCAN(eps=eps_val, min_samples=5)
    labels = dbscan.fit_predict(X)
    outliers = X[dbscan.labels_ == -1]
    print(f"이상치 개수: {len(outliers)}")
    plt.figure()
    plt.title(f"DBSCAN eps={eps_val}")
    plt.scatter(X[:, 0], X[:, 1], c=labels, cmap='Set1')
    plt.scatter(outliers[:, 0], outliers[:, 1], color='black', marker='x', label='Noise')
    plt.legend()
    plt.grid(True)
    plt.show()
```


| 함수명                        | 설명                       | 주요 파라미터              |
| -------------------------- | ------------------------ | -------------------- |
| `DBSCAN(eps, min_samples)` | DBSCAN 알고리즘 객체 생성        | `eps`, `min_samples` |
| `.fit(X)`                  | 군집화 수행                   | `X`: 입력 데이터          |
| `.fit_predict(X)`          | 군집화 수행 후 라벨 반환           | `X`: 입력 데이터          |
| `.labels_`                 | 각 데이터의 클러스터 번호 (-1은 이상치) | 없음                   |

# 10장. 차원축소

# [1] 차원 축소란 무엇인가?


## 1. 차원 축소의 개념

* 차원 축소(Dimensionality Reduction)란 **고차원 데이터를 저차원으로 변환**하는 기술임.
* 데이터의 핵심 구조나 특성을 최대한 보존하면서, **불필요한 정보 또는 잡음을 제거**함.
* 고차원 데이터는 복잡하고 계산량이 많으며, 시각화도 어렵기 때문에 차원 축소가 필요함.

---

## 2. 차원의 의미

* 데이터의 **차원**이란 각 데이터가 가지는 **속성(feature)**의 수를 의미함.

  * 예: 신체 데이터의 경우 \[키, 몸무게, 나이, 체온] → 4차원
* 차원이 증가할수록, 데이터 간의 거리나 밀도 등의 특성이 왜곡됨.

---

## 3. 차원 축소의 목적

- 차원 축소는 시각화 뿐 만 아니라, 
- 지도 학습 분류(Classification), 회귀(Regression) 알고리즘과 결합


| 목적        | 설명                              |
| --------- | ------------------------------- |
| 계산 효율성 향상 | 고차원 연산 → 연산 시간과 메모리 감소          |
| 시각적 설명력 증가  | 2차원 또는 3차원으로 변환하여 눈으로 패턴 파악 가능  |
| 노이즈 제거    | 관련 없는 특성을 제거하여 분석 정확도 향상        |
| 모델 성능 향상  | 과적합(overfitting) 방지 및 일반화 성능 개선 |
| 데이터 압축    | 저장 공간 절약 및 통신 효율성 증대            |
| 데이터 해석력 증가 | 모델의 입력 특성을 해석 가능한 주성분으로 대체 |

---

## 4. 차원 축소 기법의 분류

| 분류 기준     | 종류                        | 설명                      |
| --------- | ------------------------- | ----------------------- |
| 변환 방식 기준  | 특징 추출(Feature Extraction) | 기존 특성을 조합하여 새로운 특성을 생성함 |
|           | 특징 선택(Feature Selection)  | 기존 특성 중 중요한 것만 선택함      |
| 선형/비선형 여부 | 선형: PCA, LDA              | 직선 또는 평면으로 투영           |
|           | 비선형: t-SNE, UMAP, Isomap  | 곡선 또는 다변량 분포 유지         |
| 지도/비지도 여부 | 비지도: PCA, t-SNE, UMAP     | 레이블 없이 데이터 구조만 이용함      |
|           | 지도: LDA, 커널 PCA(부분지도 포함)  | 클래스 정보를 활용하여 구조 보존      |

---

## 5. 차원 축소의 적용 사례

| 분야     | 적용 예시                                        |
| ------ | -------------------------------------------- |
| 유전체학  | 수천 개 유전자 발현값 → 2D로 시각화, 조직/질병 구분 가능     |
| 의학영상 분석 | 고차원 이미지 해상도 → 차원 축소 후 질환 분류    |
| 금융 분석  | 주식 가격 데이터 요약, 이상 거래 탐지                       |
| 마케팅 분석 |	고객 구매 패턴 축소 → 군집화로 세그먼트 분류               |
| 자연어 처리 | 단어/문장 임베딩 벡터를 2D로 시각화하여 의미 군집 해석  |
|            |  (e.g., Word2Vec → t-SNE 시각화) |
| 추천 시스템 | 사용자-상품 매트릭스 차원 축소 후 SVD 기반 추천                |
| IoT 데이터  |	수십 개 센서 데이터 → 2차원 투영 후 이상 탐지   |
| 소셜 네트워크 |	Node 임베딩 축소 → 커뮤니티 구조 시각화   |


---

## 6. 고차원 공간에서 발생하는 문제점

(*= 차원 저주 = Curse of Dimensionality*)

* 고차원일수록 데이터가 **희소(sparse)** 해짐.
* 거리 기반 알고리즘(예: kNN, DBSCAN)의 성능이 저하됨.
* 고차원 공간에서는 모든 데이터가 **거의 같은 거리**에 있는 것처럼 느껴짐.
* 시각화와 직관적인 해석이 어려움.

# [2] 주성분 분석(PCA)과 특이값 분해(SVD)


## 1. PCA란 무엇인가?

* PCA(Principal Component Analysis)는 **고차원 데이터를 가장 잘 설명하는 방향으로 투영**하여 저차원으로 변환하는 **선형 차원 축소 기법**임.
* 데이터의 **분산이 가장 큰 축(주성분)** 을 찾고, 그 방향으로 데이터를 표현함.
* PCA는 거리 기반 기법이므로, 특성 간 스케일 차이를 없애기 위해 표준화가 반드시 필요함.
---

## 2. PCA의 직관적 설명

* 데이터를 **회전(Rotation)** 하여 가장 넓게 퍼진 방향으로 정렬함.
* 새로운 좌표계(주성분 공간)는 원래 축과 다를 수 있음.
* 가장 중요한 정보(분산이 큰 방향)만 유지하고 나머지는 버림.

---

## 3. PCA 알고리즘 수행 과정

| 단계 | 설명                                    |
| -- | ------------------------------------- |
| ①  | 데이터를 평균 0으로 정규화 (centering)           |
| ②  | 공분산 행렬 계산                             |
| ③  | 고유값(Eigenvalue)과 고유벡터(Eigenvector) 계산 |
| ④  | 고유값 순으로 정렬 후 상위 k개 선택                 |
| ⑤  | 선택한 주성분 방향으로 투영                       |

---

## 4. 수학적 정의

### ● 공분산 행렬

$$
\mathbf{C} = \frac{1}{n-1} X^\top X
$$

* $X$: 평균 제거된 데이터 행렬
* $C$: 각 특성 간 분산과 공분산을 나타냄

---

### ● 고유값 분해

$$
\mathbf{C} \cdot \mathbf{v}_i = \lambda_i \cdot \mathbf{v}_i
$$

* $\lambda_i$: 고유값 (i번째 주성분의 중요도)
* $\mathbf{v}_i$: 고유벡터 (i번째 주성분 방향)

---

### ● 투영된 데이터

$$
Z = X \cdot V_k
$$

* $V_k$: 상위 $k$개의 고유벡터로 구성된 행렬
* $Z$: k차원으로 축소된 데이터

---

## 5. 누적 분산 설명 비율 (Explained Variance Ratio)

* 각 주성분이 전체 분산에서 차지하는 비율을 의미함.
* 시각화: 스크리 플롯(Scree Plot)으로 확인

$$
\text{분산 비율} = \frac{\lambda_i}{\sum_j \lambda_j}
$$

---

## 6. SVD(Singular Value Decomposition)와 PCA의 관계

* PCA는 SVD와 밀접하게 연결됨.
* SVD는 다음과 같은 형태로 행렬을 분해함:

$$
X = U \Sigma V^\top
$$

| 구성 요소    | 의미                |
| -------- | ----------------- |
| $U$      | 좌측 직교 행렬 (샘플 방향)  |
| $\Sigma$ | 특이값 (√고유값)        |
| $V$      | 주성분 방향 (고유벡터와 동일) |

* **PCA는 사실상 SVD의 특이값과 우변 벡터만 사용하여 계산 가능함.**

rng = np.random.RandomState(1)

plt.scatter(x[:,0], x[:, 1])

# 시각화
def draw_vector(v0, v1, ax=None):
    ax = ax or plt.gca()
    arrowprops = dict(color='red',
                      arrowstyle='-&gt;',
                     linewidth=2,
                     shrinkA=0, shrinkB=0 )
    ax.annotate('', v1, v0, arrowprops=arrowprops)

# data plotting
plt.scatter(x[:, 0], x[:,1], alpha=0.2)
for length, vector in zip(mypca.explained_variance_, mypca.components_):
    v = vector * 3* np.sqrt(length)
    draw_vector(mypca.mean_, mypca.mean_ + v)
plt.axis('equal')
plt.show()

# 설명된 분산 비율 확인
print("설명된 분산 비율:", mypca.explained_variance_ratio_)
print("주성분 벡터:", mypca.components_)

# 주성분 축으로 변환된 좌표로 데이터 시각화
x_t = mypca.transform(x)
plt.scatter(x_t[:, 0], x_t[:,1], alpha=0.2)
plt.xlabel('PC1')
plt.ylabel('PC2')
plt.axis('equal')
plt.show()
```

# [3] 비선형 차원 축소: t-SNE와 UMAP

## 1. 비선형 차원 축소란?

- 비선형 차원 축소(Nonlinear Dimensionality Reduction)는 데이터의 **곡선 형태 구조**나 **복잡한 분포**를 보존하면서 저차원으로 축소하는 기법임.
- PCA처럼 직선(선형) 공간으로 투영하는 방식은 **복잡한 데이터 구조**를 잘 표현하지 못함.
- 대표적인 기법: **t-SNE**, **UMAP**

---

## 2. t-SNE (t-distributed Stochastic Neighbor Embedding)

### ● 개념
- t-SNE는 데이터 간의 **국소적 이웃 관계(local neighborhood)** 를 보존하는 저차원 임베딩 기법임.
- 고차원 공간의 점들 간 **확률적 유사도**를 계산하고, 저차원 공간에서도 이 확률 분포를 최대한 유사하게 만듦.

### ● 알고리즘 핵심
| 단계 | 설명 |
|------|------|
| ①    | 고차원 거리 → 확률 분포(P)로 변환  
| ②    | 저차원 거리 → t-분포 기반 확률 분포(Q) 생성  
| ③    | KL 발산(Kullback-Leibler Divergence)을 최소화  

\[
KL(P \parallel Q) = \sum_i \sum_j p_{ij} \log \frac{p_{ij}}{q_{ij}}
\]

### ● 주요 파라미터
| 파라미터       | 설명 |
|----------------|------|
| `perplexity`   | 이웃 수 조절 (보통 5~50) |
| `learning_rate`| 학습률 (200~1000 권장) |
| `n_iter`       | 반복 횟수 (최소 250 이상 권장) |

### ● 장점과 단점

| 장점                     | 단점                                 |
|--------------------------|--------------------------------------|
| 시각화 품질이 매우 뛰어남 | 학습 시간이 길고 느림                |
| 국소 구조(이웃 관계) 보존 | 전체 구조(전역 거리)는 왜곡될 수 있음 |
| 파라미터에 민감함        | 결과가 비결정적 (매번 다름)          |

---

## 3. UMAP (Uniform Manifold Approximation and Projection)

### ● 개념
- UMAP는 **거리 보존을 기반으로 한 비선형 임베딩 기법**임.
- t-SNE와 유사하지만, **속도가 빠르고 전체 구조 보존 능력도 뛰어남**.
- **위상수학(Topological Data Analysis)** 개념을 기반으로 설계됨.

### ● 알고리즘 핵심
| 단계 | 설명 |
|------|------|
| ①    | 고차원 공간에서 그래프 생성 (이웃 연결)  
| ②    | 저차원에서 유사한 그래프 생성  
| ③    | 두 그래프 간의 차이를 최소화  

### ● 주요 파라미터

| 파라미터       | 설명 |
|----------------|------|
| `n_neighbors`  | 이웃의 수 (지역 보존 정도 결정) |
| `min_dist`     | 포인트 간 최소 거리 (작을수록 촘촘하게) |
| `metric`       | 거리 계산 방식 (`euclidean`, `cosine` 등) |

### ● 장점과 단점

| 장점                             | 단점                         |
|----------------------------------|------------------------------|
| 빠른 실행 시간                   | 이론적으로 복잡함           |
| 전역+국소 구조를 모두 보존 가능 | 결과 해석이 다소 어려움     |
| 지도 학습으로 확장 가능 (semi-supervised) |                             |

from sklearn.datasets import fetch_openml
from sklearn.decomposition import PCA
from sklearn.manifold import TSNE
import matplotlib.pyplot as plt
import seaborn as sns

# MNIST 데이터 불러오기 (784차원)

# PCA로 50차원으로 축소
pca = PCA(n_components=50)
X_pca = pca.fit_transform(X)

tsne = TSNE(n_components=2, perplexity=30, random_state=0)

plt.xlabel("t-SNE 1")
plt.ylabel("t-SNE 2")
plt.grid(True)
plt.show()
```
